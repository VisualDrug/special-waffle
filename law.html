Удалить надстройку диагностики

1. Запустите обозреватель Internet Explorer: нажмите кнопку Пуск и выберите Internet Explorer.

2. Нажмите кнопку Сервис и выберите команду Управление надстройками.

3. Чтобы вывести все элементы ActiveX, выберите в разделе Отобразить параметр Загруженные элементы управления.

4. Щелкните элемент ActiveX, который называется ConsIETester, и нажмите кнопку Подробнее.

5. В диалоговом окне Дополнительные сведения нажмите кнопу Удалить. Если отображается запрос на ввод пароля администратора или его подтверждения, укажите пароль или предоставьте подтверждение.

2. Нажмите кнопку Сервис, а затем выберите Надстройки.

3. В области Показать выберите пункт Загруженные элементы управления для отображения всех элементов управления ActiveX.

5. В диалоговом окне Дополнительные сведения нажмите кнопку Удалить. Введите пароль администратора или подтверждение пароля, если появится соответствующий запрос.

Если появилось сообщение об ошибке и удалить компонент не удалось

1. Закройте все окна обозревателя Internet Explorer.

2. Повторите заново процедуру удаления элемента управления ActiveX в соответствии с инструкциями.

1. Запустите обозреватель Mozilla Firefox: нажмите кнопку Пуск и выберите Mozilla Firefox.

2. Выберите в меню пункт Инструменты, а затем выберите подпункт Дополнения.

3. В открывшемся списке выберите закладку Дополнения.

4. В списке дополнений нажмите кнопку Удалить напротив приложения Consultant+ compatibility test + clipboard addon
