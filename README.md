# Жить выгоднее — русский гайд

Статический сайт (без сборки и серверов): 765 советов из справочника «高性价比人生指南»
(https://github.com/eternity4719/HowToLiveBetter, CC BY 4.0) в полном русском переводе (все поля, 34 вводных текста, 9 длинных статей).
Перевод неофициальный; цифры и нормы относятся к материковому Китаю.

## Запуск
Откройте `index.html` в браузере (работает офлайн) или `python3 -m http.server`.

## Публикация на GitHub Pages
1. Создайте репозиторий, залейте эти файлы в ветку `main`.
2. Settings → Pages → Source: **GitHub Actions** (workflow уже лежит в `.github/workflows/pages.yml`).
3. Сайт появится на `https://<логин>.github.io/<репозиторий>/`.

Без Actions: Settings → Pages → Deploy from a branch → `main` / root.

## Файлы
- `index.html`, `app.js`, `names.js` — сайт; `data/chNN.js` — разделы (грузятся по мере открытия), `data/docs.js` — длинные статьи.
- `src/` — сокращённый перевод (`ru/`); полный перевод лежит прямо в `data/`.
